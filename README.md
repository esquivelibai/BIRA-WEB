# BIRA · Real Food Endurance

Landing / presentación del proyecto **BIRA** — barra energética natural a base de
cereza revalorizada y proteína vegetal. Trabajo del **PBL06 (Ereindajan erronka)**,
Diseinu Industrialeko Ingeniaritza eta Produktu Garapena · Mondragon Unibertsitatea.

Web estática, sin dependencias: **HTML + CSS + JavaScript vanilla**. Bilingüe (EU/ES).

## Ver la web en local

Opción A — doble clic en **`abrir-web.bat`** (Windows).

Opción B — con Node instalado:

```bash
node server.js
# abre http://localhost:4317
```

(También se puede abrir `index.html` directamente en el navegador.)

## Estructura

```
index.html      Marcado y todo el contenido (textos EU/ES con data-eu / data-es)
styles.css      Estilos y diseño (paleta y tipografía del manual de marca)
script.js       Idioma, contadores, marquee, efecto 3D del cursor en el hero
assets/         Imágenes (renders de producto, packaging, personas, etc.)
server.js       Servidor estático local para previsualizar
```
